# دليل الاستخدام — العربية

## التشغيل محليًا

```bash
git clone https://github.com/amirrezapanahi/chess-algorithm-lab.git
cd chess-algorithm-lab
npm ci
npm run dev
```

افتح العنوان الذي يعرضه Vite. لا تحتاج إلى خادم خلفي أو قاعدة بيانات.

## طريقة الاستخدام

1. اختر تمرينًا من الترويسة.
2. اقرأ **المسألة** وأظهر التلميحات تدريجيًا.
3. اكتب دالة متزامنة `solve(input)` في تبويب **الكود**.
4. اضغط **تشغيل** أو `Ctrl/Cmd + Enter`.
5. استخدم الخط الزمني لمراجعة كل حدث تم التحقق منه.
6. اضغط **اختبار** لتشغيل أدوات التحقق الرياضية العامة.
7. صدّر الحل كملف `.js` قبل الانتقال إلى جهاز آخر.

يُحفظ الكود تلقائيًا في IndexedDB داخل هذا المتصفح ولا تتم مزامنته مع GitHub.

```js
function solve(input) {
  return input.value * 2;
}

function* trace(input) {
  yield { type: "visit", row: 0, col: 0 };
  yield { type: "complete", message: "تم" };
}
```

راجع [[Code-Examples|أمثلة الكود]] و[[Exercise-API|واجهة التمارين]] للمزيد.

## البداية من الصفر: افتتاحيتك الأولى

اختر **01 · ابدأ هنا**. تظهر القطع الـ32 كلها مباشرة: القطع السوداء في الصفين 8 و7 والبيضاء في الصفين 1 و2. تمتد الأعمدة من `a` إلى `h` والصفوف من `1` إلى `8`.

تكفي أربع أفكار: تعرّف `function solve()` الدالة التي يشغّلها المختبر؛ النص بين علامتي اقتباس هو **سلسلة نصية**؛ تنشئ `[]` **مصفوفة مرتبة**؛ وتعيد `return` الإجابة.

```js
function solve() {
  return [
    "e2-e4",
    "e7-e5",
    "g1-f3",
    "b8-c6",
  ];
}
```

يحرّك الطرفان بيدق الملك ثم يطوّر كل طرف حصانًا. اضغط **تشغيل** وافتح **الرقعة** واستخدم الخط الزمني، ثم اضغط **اختبار**. النتيجة المتوقعة هي نجاح `1/1`.

الأخطاء الشائعة: نسيان علامات الاقتباس أو الفواصل، تغيير ترتيب النقلات، استعمال شرطة مختلفة أو كتابة `E2-E4` بأحرف كبيرة. لا تحتاج إلى `input` أو إلى كتابة `trace()` في هذا الدرس.
