# Руководство — Русский

## Локальный запуск

```bash
git clone https://github.com/amirrezapanahi/chess-algorithm-lab.git
cd chess-algorithm-lab
npm ci
npm run dev
```

Откройте адрес, показанный Vite. Серверная часть и база данных не нужны.

## Как пользоваться

1. Выберите задачу в верхней панели.
2. Прочитайте **Условие** и открывайте подсказки по очереди.
3. Напишите синхронную функцию `solve(input)` во вкладке **Код**.
4. Нажмите **Запустить** или `Ctrl/Cmd + Enter`.
5. Просматривайте проверенные события по временной шкале.
6. Нажмите **Тесты**, чтобы запустить открытые математические проверки.
7. Экспортируйте решение `.js` перед переходом на другое устройство.

Код автоматически хранится в IndexedDB этого браузера и не отправляется в GitHub.

```js
function solve(input) {
  return input.value * 2;
}

function* trace(input) {
  yield { type: "visit", row: 0, col: 0 };
  yield { type: "complete", message: "Готово" };
}
```
