# Руководство — Русский

## Локальный запуск

```bash
git clone https://github.com/amirrezapanahi/chess-algorithm-lab.git
cd chess-algorithm-lab
npm ci
npm run dev
```

Откройте адрес, показанный Vite. Серверная часть и база данных не нужны.

## Как пользоваться

1. Выберите задачу в верхней панели.
2. Прочитайте **Условие** и открывайте подсказки по очереди.
3. Напишите синхронную функцию `solve(input)` во вкладке **Код**.
4. Нажмите **Запустить** или `Ctrl/Cmd + Enter`.
5. Просматривайте проверенные события по временной шкале.
6. Нажмите **Тесты**, чтобы запустить открытые математические проверки.
7. Экспортируйте решение `.js` перед переходом на другое устройство.

Код автоматически хранится в IndexedDB этого браузера и не отправляется в GitHub.

```js
function solve(input) {
  return input.value * 2;
}

function* trace(input) {
  yield { type: "visit", row: 0, col: 0 };
  yield { type: "complete", message: "Готово" };
}
```

Дополнительные примеры: [[Code-Examples]] и [[Exercise-API]].

## С нуля: ваш первый дебют

Выберите **01 · Начало**. На доске сразу стоят все 32 фигуры: чёрные на 8-й и 7-й горизонталях, белые на 1-й и 2-й. Вертикали обозначаются от `a` до `h`, горизонтали — от `1` до `8`.

Достаточно четырёх понятий: `function solve()` объявляет функцию лаборатории; текст в кавычках — **строка**; `[]` создаёт упорядоченный **массив**; `return` возвращает ответ.

```js
function solve() {
  return [
    "e2-e4",
    "e7-e5",
    "g1-f3",
    "b8-c6",
  ];
}
```

Белые и чёрные двигают королевские пешки, затем развивают по коню. Нажмите **Запустить**, откройте **Доска** и используйте шкалу шагов; затем нажмите **Тесты**. Ожидаемый результат — `1/1`.

Частые ошибки: пропущенные кавычки или запятые, неверный порядок, другой знак тире или запись `E2-E4` заглавными буквами. В этом уроке не нужны `input` и собственная `trace()`.
