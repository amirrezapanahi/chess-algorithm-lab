# راهنمای فارسی

## اجرای محلی

```bash
git clone https://github.com/amirrezapanahi/chess-algorithm-lab.git
cd chess-algorithm-lab
npm ci
npm run dev
```

نشانی نمایش‌داده‌شده توسط Vite را در مرورگر باز کنید. برنامه کاملاً داخل مرورگر اجرا می‌شود و به بک‌اند یا پایگاه‌داده نیاز ندارد.

## روش استفاده

1. تمرین را از هدر انتخاب کنید.
2. در تب **صورت مسئله** توضیح و راهنمایی‌ها را بخوانید.
3. تابع همگام `solve(input)` را در تب **کد** بنویسید.
4. دکمهٔ **اجرا** یا `Ctrl/Cmd + Enter` را بزنید.
5. با تایم‌لاین، اجرای الگوریتم را قدم‌به‌قدم بررسی کنید.
6. با **آزمون**، اعتبارسنجی ریاضی عمومی را اجرا کنید.
7. برای انتقال بین دستگاه‌ها، کد را به فایل `.js` خروجی بگیرید.

کد به‌صورت خودکار در IndexedDB همین مرورگر ذخیره می‌شود؛ این ذخیره‌سازی به GitHub همگام نمی‌شود.

## نمونهٔ حداقلی

```js
function solve(input) {
  return input.value * 2;
}
```

نمایش گام‌ها اختیاری است:

```js
function* trace(input) {
  yield { type: "visit", row: 0, col: 0 };
  yield { type: "complete", message: "پایان" };
}
```

برای نمونه‌های بیشتر [[Code-Examples|نمونه‌کدها]] و برای قرارداد هر تمرین [[Exercise-API|رابط تمرین‌ها]] را ببینید.

## شروع از صفر: اولین اوپنینگ

تمرین **۰۱ · شروع از صفر** را انتخاب کنید. صفحه از همان ابتدا همهٔ ۳۲ مهره را دارد: مهره‌های سیاه در ردیف‌های ۸ و ۷ و مهره‌های سفید در ردیف‌های ۱ و ۲ قرار دارند. ستون‌ها از `a` تا `h` و ردیف‌ها از `1` تا `8` نام‌گذاری می‌شوند.

برای شروع فقط چهار مفهوم جاوااسکریپت لازم است:

- `function solve()` تابعی است که آزمایشگاه آن را اجرا می‌کند.
- متن داخل کوتیشن مانند `"e2-e4"` یک **رشته** است.
- براکت‌های `[]` یک **آرایهٔ مرتب** می‌سازند.
- `return` پاسخ را به آزمایشگاه برمی‌گرداند.

```js
function solve() {
  return [
    "e2-e4",
    "e7-e5",
    "g1-f3",
    "b8-c6",
  ];
}
```

سفید پیادهٔ شاه را جلو می‌برد، سیاه همان حرکت را پاسخ می‌دهد و سپس هر دو طرف یک اسب را توسعه می‌دهند. **اجرا** را بزنید، وارد **صفحه** شوید و با تایم‌لاین حرکت‌ها را ببینید. سپس **آزمون** را اجرا کنید؛ نتیجهٔ درست `1/1` موفق است.

خطاهای رایج: فراموش‌کردن کوتیشن یا ویرگول، استفاده از خط تیرهٔ اشتباه، جابه‌جاکردن ترتیب حرکت‌ها و نوشتن `E2-E4` با حروف بزرگ. در این تمرین نیازی به `input` یا نوشتن `trace()` ندارید.
