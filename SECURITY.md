# Security policy

Please report suspected sandbox escapes, cross-site scripting, or dependency supply-chain issues privately to the repository maintainers through GitHub's private vulnerability reporting feature when it is enabled.

Include the affected commit, browser, minimal reproduction, expected impact, and whether the issue crosses the QuickJS/Worker boundary. Do not include real student data.

The current security design and known limitations are documented in [docs/security.md](docs/security.md).
